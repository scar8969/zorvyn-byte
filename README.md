# Zorvyn + Bite

A React + Vite web application for Zorvyn financial systems with integrated Bite food expense tracking app.

## Features
- Zorvyn: Secure financial systems for startups and SMEs
- Bite: Food expense tracking with reports, categories, and budget alerts

## Tech Stack
- React 19 + Vite
- Tailwind CSS
- React Router
- Recharts for data visualization
- LocalStorage for data persistence

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
